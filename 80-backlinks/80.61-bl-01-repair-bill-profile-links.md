# BL-01 — Repair the Bill.com profile links

- ID: BL-01
- Status: Open
- Owner: Tyler Wilcox
- Effort: Small. The profile already exists. The work is editing the URLs on it.
- Expected impact: The live BILL partner listing (the lost export row was DA 56, follow) stops sending visitors to a 404 and to the homepage. The old preview URL is already 404 and does not need a new redirect if the public profile is the one people use.

## Rationale

Ubersuggest lost the preview URL on 2026-10-09. That URL returned 404 on November 25. The partner profile returned 200:

`https://www.bill.com/find-an-accountant/partner/velu-certified-public-accountant`

Its HTML links to `https://velu.us/resources/`, which returns 404, and prints `https://velu.us/services/`, which 301s to the homepage. `https://velu.us/get-started/` on the same profile returns 200. Evidence is in [80.26](80.26-lost-link-status-2026-11-25.md).

## Acceptance criteria

- The resources control points at a live velu.us URL, or it is removed.
- The services sentence points at a live service URL, not `/services/`.
- Get Started still points at `https://velu.us/get-started`.
- A fetch of the profile shows those targets, and each target returns 200.
- The change is recorded in [80.80](80.80-implementation-log.md).

## Out of scope

Do not create a redirect from `/resources/` to the homepage as a substitute for editing the profile. `/resources/` was left without a redirect in the June audit.
