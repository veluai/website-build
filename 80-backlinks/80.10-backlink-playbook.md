# Backlink playbook

How to repeat the work in this folder. The November 25, 2026 audit is the
first one filed here. The June 29, 2026 Search Console pass stays in
[30.45](../30-current-site/30.45-backlink-preservation-audit-2026-06-29.md)
and [30.46](../30-current-site/30.46-backlink-preservation-audit-2026-06-29.csv).

## Run an audit

1. Pull referring domains, new domains, and lost domains from the same tool
   and the same day. Record the tool, the date, and any overview figures
   (authority, backlink count, referring-domain count) that are not rows in
   the export.
2. Save three CSVs in this folder, one row per domain, with the source page,
   the velu.us target, the anchor, authority, follow or nofollow, spam score,
   and dates. Keep the export's row counts. Do not silently drop rows.
3. Write a dated summary. Link the June audit for anything it already
   decided. Do not paste that audit in again.
4. Group targets by path. Check each distinct velu.us URL with a single-hop
   request and a followed request. Record the status you actually got.
5. Write the action list: reclaim a lost legitimate listing, restore a guide
   that has no live equivalent, outreach only where a real editor can change
   the link, and a monitor note for spam.

Leave the previous audit's files in place.

## Add a redirect

Velu has no application redirect file. Redirects are GoHighLevel URL rules
for domain `velu.us`.

Before adding a rule:

- Confirm the source returns 404 (or a chain that does not already end on the
  right page).
- Confirm the destination is a live canonical URL and returns 200. Home is
  `https://velu.us/`. Every other destination has no trailing slash.
- Prefer the page that covers the same service. The current service URLs are
  in [30.10-current-site-index.md](../30-current-site/30.10-current-site-index.md).
- If the URL is a guide or template and no live page is that resource, do not
  redirect it to the homepage. Record a restoration recommendation and the
  linking domains.
- Do not add a `/wp-content/uploads/` rule. On November 25, 2026 four of those
  rules were stored and the URLs still returned 404. The 404 had no
  `x-ghl-serve-region` header. Page-path rules returned 301 with that header.
  The upload rules were deleted the same day. Search the redirect list for
  `wp-content` before assuming an old upload rule is still there.

Enter the rule as:

- Domain: `velu.us`
- Path: the path only, with a leading slash and no trailing slash
- Target: the full canonical URL
- Action: `url`

GoHighLevel stores the path without a trailing slash. Test both the slash and
no-slash forms when the old URL used a slash. A working rule is a first
response of 301 and a final response of 200 on the destination. Record the
GoHighLevel rule id, the old URL, the new URL, the linking domains, and the
live result in a dated CSV in this folder.

Rollback is deleting that rule id. Do not delete the June launch rules or the
November 20 `/home` rule while rolling back a later audit.

The launch list of 31 stays in
[30.43](../30-current-site/30.43-pre-publication-launch-redirect-map.csv). New
backlink rules are recorded here, not appended to that launch file. Note the
new rules in
[30.25](../30-current-site/30.25-gohighlevel-redirect-implementation-checklist.md)
so the entry history stays in one place.

## Outreach and reclamation

Use outreach when a real profile or editorial page points at a dead or wrong
URL and someone can edit it. A directory listing that disappeared is a
reclamation task, not a redirect. Check whether the old target already 301s
before asking the publisher to change it.

Do not ask a publisher to point a guide link at the homepage while the guide
is still a restoration item.

## Disavow

Keep a candidate list in this folder. Do not upload a disavow file unless
Tyler asks.

Google generally ignores mass directory and private-network links of the kind
in the November 25 export: repeated anchors about buying backlinks, a shared
path such as `/dir/outreach-link-building-224659`, and high spam scores. A
disavow is optional for that pattern. Monitoring the next export is the
default. Disavow when Tyler decides the pattern is being treated as Velu's
own links, or when a manual action says so. This playbook does not create a
Search Console disavow upload.

## What not to do

- Do not redirect every old WordPress URL. The launch audit separated
  preserve, archive, and discard on purpose.
- Do not invent a Vercel or framework redirect file. This repository does not
  build or deploy the site.
- Do not copy client data, credentials, or a full raw tool payload that
  contains either. The domain-level CSV is the snapshot.
