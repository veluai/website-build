# BL-04 — Correct the citations already known to be stale

- ID: BL-04
- Status: Open
- Owner: Tyler Wilcox
- Effort: Small for LocalityBiz if an owner edit exists. The Chamber listing still has to be opened.
- Expected impact: People and crawlers stop seeing the old 617 S 14th St address. This is a name-address-phone fix, not a link-building program.

## Rationale

[30.22](../30-current-site/30.22-google-search-follow-up.md) already records that LocalityBiz showed 617 S 14th St #204 and that no public edit control was available. That correction is still the open item. This recommendation does not re-investigate it. It is the place that work is tracked from the backlink backlog.

A November 25 search snippet for the ChamberofCommerce.com Velu listing showed the same old street address and `http://www.velu.us/`. A direct fetch of that URL returned a short page that did not contain the address. The snippet is unverified until the listing body is opened. See [80.30](80.30-citation-directory-gap-2026-11-25.md).

## Acceptance criteria

- LocalityBiz either shows 1402 Jones St #1004, `(402) 578-0622`, and `https://velu.us/`, or the log says the edit is still blocked and why.
- The Chamber listing is opened. If it still shows the old address or `www`, it is corrected or the block is logged. If the snippet was stale, the log says what the page actually shows.
- Google Business Profile is not edited unless the opened profile disagrees with the October 28 record.

## Out of scope

Do not create Yelp, BBB, Gusto, or Xero listings in this item. That decision is BL-05.
