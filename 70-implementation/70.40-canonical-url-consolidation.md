## Approved URL form

| Piece | Form |
| --- | --- |
| Host and protocol | `https://velu.us` (apex, HTTPS) |
| Homepage | `https://velu.us/` |
| Every other public page | `https://` + apex host + path, with no trailing slash |
| `/home` and `/home/` | 301 to `https://velu.us/` |
| `http://`, `www`, and non-root trailing-slash URLs | 301 to the row above |

The root path keeps its slash. `https://velu.us` and `https://velu.us/` are the
same homepage, and the declared canonical is `https://velu.us/`. No other page
uses a trailing slash. That is the one slash rule, and it matches the URLs
already stored in page SEO records, JSON-LD, the footer, and the June 28
redirect destinations. GoHighLevel has dropped non-root destinations that were
entered with a trailing slash back to Home; those destinations stay without a
slash.

### 1. Primary domain, HTTPS, and www

Read the domain settings before changing them. The November 20 check already
sends `https://www` and `http://velu.us` to `https://velu.us/` in one hop, and
sends `http://www` there in two hops.

- Set the primary domain to `velu.us` on HTTPS when a primary-domain control is
  present and it currently shows `www` or `http`.
- Turn on the platform control that forces HTTPS and sends `www` to the apex,
  when that control exists and is off.
- Request `http://www.velu.us/` again with caching bypassed. The preferred
  result is one 301 whose Location is `https://velu.us/` or `https://velu.us`,
  then a 200 homepage whose canonical is `https://velu.us/`.
- When the response is still the two-hop chain above, leave that chain. It
  already reaches the apex. A second redirect rule for the same hop can loop.
- When the response is a loop, a 200 on `http://www`, or a landing on `/home`,
  restore the photographed settings before continuing.

### 4. Fold `/home` into `/`

GoHighLevel stores a redirect source without a trailing slash, and a non-root
destination entered with a trailing slash can resolve to Home. The homepage
destination is the exception: it stays `https://velu.us/`.

1. Read the Home page slug and whether that page is assigned as the domain
   homepage. Write both down. Leave the homepage assignment as it is.
2. Add one 301. Source: `/home`. Destination: `https://velu.us/`. Add no rule
   from `/` to `/home`, and no second source of `/home/`.
3. Retest with caching bypassed, in this order:
   - `https://velu.us/home` returns 301 to `https://velu.us/` and the final
     page is 200 with canonical `https://velu.us/`.
   - `https://velu.us/home/` does the same, either directly or through one
     extra hop, and does not return 200.
   - `https://velu.us/` stays 200 and does not redirect to `/home`.
   - `https://velu.us/get-started`, `/about-us`, and `/digital-coffee` stay on
     those pages.
4. When `/home` is still 200, the page slug is winning over the redirect.
   Continue only if the slug is `home` and the domain homepage assignment is
   separate from that slug. Change the slug to a path that is not linked and
   not already a redirect source. Record the old slug. Retest the root first.
   The root must still be the homepage. Then retest `/home`.
5. When the root moves, the test loops, or another real page falls through to
   Home, restore the photographed slug, delete the new `/home` rule, and stop.
   The June redirect set stays.
